## Finding and resolution

**IR-01 — National-line poverty cross-country comparability (material analytical finding).** The comparison function originally allowed a same-year numerical gap for SI.POV.NAHC across countries merely because the code and percentage unit matched. The dashboard could also rank these rates. Country-specific national poverty definitions do not provide equivalent international welfare thresholds, and a general methodological warning was insufficient in the separately selectable comparison view.

Resolution inspected in code: `comparableGap` now returns null for SI.POV.NAHC across different countries; Dashboard disables its peer rank with an explicit national-definition explanation; CountryComparisonTool shows its own warning following its selected indicator. A regression test was added by the root agent. Its execution result belongs to the root's final test receipt and is not asserted by this review. Country trends and attributed raw values remain visible for inspection, without a computed cross-country gap or rank.

No additional substantive numerical or definition blocker was found in the inspected candidate report and UI path after IR-01 was addressed. This conclusion does not close the external approval, national footnote, original-vintage, accessibility, operational monitoring or staging verification gates.

**IR-02 — Row-level welfare and population comparability caveats (material analytical finding).** The subsequent footnote audit identified 514 nonempty observation notes. Independent inspection confirmed the count, Uzbekistan's income-based Gini versus Tajikistan's consumption-based Gini, national poverty source notes and Georgia's 2024 census-based population note. The raw dataset did not change numerically; these caveats affect interpretation.

Resolution inspected in source: UI observation details and tabular values now preserve notes, PPP basis, source-update date and observation status; CSV exports retain the same fields. National poverty, Gini and bottom-quintile shares are in the blocked cross-country gap/rank set, while asynchronous ranks remain disabled. Canonical policy and methodology sources, JSON, Markdown and fresh PDFs now describe these differences, with no changed numerical claims. Regression-test execution and browser evidence remain in root receipts. These changes address the identified misleading-comparison risk; they are not an exhaustive national-methodology certification or external statistical signoff.
